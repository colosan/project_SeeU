# 설계와 결정 사항

결정이 바뀌면 이 문서를 고친다. 날짜는 결정한 날.

## 게임 개요
- 시유(SeeU, SBS A&T)를 비롯한 여러 보컬로이드 캐릭터가 나오는 **비영리·무료 팬게임**. itch.io 웹 빌드(Chrome 기준) 배포 예정.
- 엔진: Godot 4.x, GDScript. 현재는 `D:\MIDAS\godot`의 직접 빌드(4.8 dev)를 쓰지만 **내보내기 템플릿이 없어 웹 빌드 불가** → 공식 안정판으로 옮길 예정(사용자가 설치).
- 장르: 탑다운 쯔꾸르풍 RPG. 상하좌우 4방향 이동(대각선 없음, 나중에 누른 축 우선).

## 세계관 (2026-10-15~16)
- 게임의 목표는 **거대한 건물을 오르는 것**. 하늘·태양이 보이는 야외는 없다.
- 설국열차처럼 **위층일수록 화려하고, 아래층일수록 가난하다**. 층마다 팔레트와 소품을 그 단계에 맞춘다.
- **시작: 지하 로봇 고물상.** 위층에서 버린 고물이 천장 슈트로 떨어져 쌓이는 곳. 불량품 로봇들이 버려지는 고철장(아스트로 보이·A.I.류) 느낌. 시유는 슈트로 떨어져 고물 산 앞 **낡은 양탄자 위에서 깨어난다**(언더테일 꽃밭 오마주).
- 지하 출구 밖에는 **낡은 화물 엘리베이터**가 있고, 이것을 타고 각 스테이지로 간다. 엘리베이터는 모든 층을 잇는 공용 공간.
  (2026-10-16) 출구 → 짧은 복도(엘리베이터 홀, 지하라 회색이지만 더 깨끗함) → 복도 끝 오목한 자리에 철창문 엘리베이터(층 선택판·탑승·도착 연출은 UI 절, 갈 수 있는 위층은 아직 없음).

## 세계 컨셉: 인터넷 속 가상 세계 (2026-10-16, 사용자 결정)
- 구체화한 설정서: [WORLD.md](WORLD.md) (층 구성, 세계 법칙, 주민, 이야기 초안, 미정 항목)
- 이 세계는 **전뇌세계·가상세계·버추얼 월드**, 즉 인터넷 안의 세상이다. 모든 맵은 이 컨셉으로 디자인한다.
  현실 공간처럼 보이더라도 "데이터가 만든 공간"이라는 단서가 화면 곳곳에 있어야 한다.
- 지금까지의 설정을 이 컨셉으로 읽으면:
  - 거대한 건물 = 인터넷 속 데이터 구조물. 위로 갈수록 화려함 = 잊힌/오래된 데이터 → 인기·주목받는 콘텐츠.
  - 지하 고물상 = 삭제·폐기된 데이터가 모이는 **휴지통/쓰레기 수집 구역**. 천장 슈트 = 위층에서 지운 데이터가 떨어지는 경로.
  - 버려진 안드로이드 = 쓰지 않게 된 아바타, 단종된 음성 모델의 몸체. 엘리베이터 = 층 사이를 오가는 데이터 통로.
  - (제안, 확정 아님) 시유는 판매가 끝난 VOCALOID3 보이스뱅크 → 휴지통에서 깨어나 꼭대기로 올라가는 이야기와 맞물린다.
- 시각 어휘(층에 맞게 골라 쓴다): 깨진 UI 창·오류 대화상자, 찢어진 파일·폴더 아이콘, 텍스처가 빠진 체크무늬 블록(글리치),
  떠 있는 커서, 로딩 표시, 와이어프레임 조각, 데이터 패킷이 흐르는 케이블, 깜빡이는 홀로그램 아바타, 단종 소프트웨어 상자, 404 같은 코드 조각.
- 지하는 이런 디지털 단서를 **낡고 깨진 상태**로, 칙칙한 회색 속 소량만. 위층일수록 깨끗하고 화려한 UI·네온·무대 연출로.
- **인터넷 공학 요소와 밈을 섞는다.** 글자 설명보다 **사물로 보여 주는 말장난**을 우선한다
  (버그=기어다니는 벌레, 스팸=통조림, 쿠키=쿠키 통, 방화벽=불타는 벽, 트로이 목마=나무 말, 클라우드=구름 저장소,
  패킷 손실=흩어진 소포, 캐시=동전 상자, 가비지 컬렉터=청소 로봇, 핑=소나 반사음).
  유명 밈(밈 캐릭터 포함)도 우리 그림체로 다시 그린 오마주로 사용한다(2026-10-16 사용자 결정: 비영리 무료라 위험을 감수).
  회사 로고·상표 문구는 넣지 않고, 외부 이미지를 베끼지 않는다. 밈 기반 소품은 docs/WORLD_PROPS.md에 원본을 표시해 배포 전에 검토·교체할 수 있게 한다.
- 층별 어휘(초안):
  - 지하(휴지통): 삭제된 파일·찢어진 폴더, 404/오류 창, 텍스처 빠진 블록, 버려진 아바타, 스팸 통조림, 버그 벌레, 쓰레기 수집 로봇, 다이얼업 모뎀·랜선.
  - 하층(레거시 서버): 서버 랙 골목, 랜선 덩굴, 깜빡이는 LED, 느린 로딩, 캐시 금고, 핑 소나.
  - 중층(커뮤니티·포럼): 게시판 광장, 댓글 말풍선, 좋아요 하트, 이모티콘, 짤방 액자.
  - 상층(스트리밍·인기 콘텐츠): 무대, 실시간 채팅 흐름, 후원 알림, 트렌딩 차트, 네온 광고판.
  - 최상층(서비스 운영진·알고리즘): 깨끗한 화이트 UI, 추천 알고리즘 기계, 방화벽 관문.
- 색 예외: 청록(glow) 하나가 강조색이지만, 데이터 손상(글리치)은 **탁한 자홍(corrupt)** 을 두 번째 강조로 소량 허용한다.

## 화면·해상도
- 창 1920x1080 = 배경 픽셀 640x360의 정확히 3배. **[왼쪽 패널 420 | 게임 화면 1080 | 오른쪽 패널 420]**, 위아래 띠는 두지 않는다(난잡함 — 사용자 결정).
  배율은 3배 유지(사용자 결정). **창이 더 크거나 넓으면 패널은 비율대로 고정, 남는 폭은 게임 화면이 가져간다**(`window/stretch/aspect="expand"`).
  **화면 배율은 정수만**(사용자 결정, `Game._fit_window`): 1080p·1440p는 1배, 4K는 2배 — 1440p에서 전체가 1.33배로 늘어 픽셀이 고르지
  않던 것을 없앴다. 정수배를 넘는 나머지는 전부 가운데 게임 칸으로(1440p 전체 화면 = 게임 칸 1720x1440, 그림은 그대로 3배라 방 주변이
  더 보인다). 1080보다 작은 창만 부드럽게 줄인다. 오른쪽 스탠딩은 패널 아래에 붙어 있어 패널이 길어져도 신발은 밖으로 빠진다.
  게임 화면 둘레에 금속 테두리 + 네 모서리 청록 HUD 꺾쇠(`scripts/ui/view_frame.gd`), 패널은 게임 쪽 안쪽 가장자리에 그림자(`UiStyle.edge_shade`),
  패널 제목은 모두 같은 규칙(`UiStyle.header`: THE STACK / ON AIR / STATUS). F11 또는 Alt+Enter = 전체화면(창 모드는 프레임이 가끔 튐).
  움직임은 물리 보간(144Hz 화면에서도 매끄럽게), 맵은 시작할 때 미리 불러 둔다(이동 순간 멈칫 없음).
  게임 화면은 SubViewport 960x1080(배경 320x360). 화면보다 작은 방은 가운데 놓이고(`player.gd` 카메라 범위),
  **실제 방만 렌더링된다**(사용자 결정): 방 사각형 밖과, 방 안의 벽 윗면·빈 칸은 모두 같은 "렌더링 안 된 공간" 무늬
  (어두운 바탕 + 원본 8px 간격 점 격자). 조명 패스가 벽 윗면(KIND_CAP)·빈 칸에 빛 0을 주고 합성 셰이더가 그 자리를 무늬로 칠한다
  (`light.gdshader`, `composite.gdshader`). 앞쪽 벽 층이 소품 위에 그려지므로 벽 뒤에 선 것은 그 무늬에 가려진다. 방 둘레 테두리선은 없음.
- 배경은 원본 픽셀을 3배로 표시. **맵은 가로 320, 세로로 긴 형태가 기본**(사용자 결정): 화면 칸(320x360)보다 길면 카메라가 위아래로 따라간다.
  지하 시작 방은 320x240 그대로(사용자 결정). 엘리베이터 홀은 320x480: 왼쪽 아래 입구 → 오른쪽으로 → 위로 긴 복도 끝 엘리베이터.
- **벽은 두께가 있는 실제 물체**(사용자 결정): 옆벽·앞벽·막힌 덩어리의 윗면을 `*_front.png` 층으로 소품·캐릭터 위에 그린다.
  앞벽 높이는 원본 24px(~1.1 m): 바로 뒤에 놓인 고물·시유의 아랫부분이 가려진다. 소품 바닥은 벽에 들어가지 않는다(레이아웃 검사).
- 시유 스프라이트는 128px, 1배(배경보다 픽셀이 가늘다 — 사용자 결정).
- 크기 기준: 시유 ≈ 배경 픽셀 37px(1.65 m) → 배경 1px ≈ 4.5 cm. 문 높이 ≈ 47px.

## UI
- **패널은 칸으로 나누지 않는다**(사용자 결정): 패널마다 그림 한 장이 패널을 채우고, 글자·작은 요소는 그 위에 얹는다(테두리 상자 금지,
  아래쪽은 그라데이션으로 어둡게 깔고 글자에 어두운 외곽). 색은 재질 램프(`scripts/ui/ui_style.gd`). 패널 그림은 아래(왼쪽 탑 일러스트, 오른쪽 층 배경·스탠딩).
  - 왼쪽 `scenes/ui/map_panel.tscn`: **거대한 세로형 지도 일러스트 한 장**(층별 칸 아님). 패널은 그 지도를 보는 창이고 현재 위치로 스크롤된다.
    현재 위치는 지도 위 깜빡이는 표시(어두운 테두리를 둘러 어느 그림 위에서도 보이고, 가장자리 그림자보다 위층에 그림, 맵을 옮기면 새 자리로 미끄러져 감) + 위쪽 글자(층 · 장소). 지도 그림은 `map_texture`, 장소 좌표·이름·층은 `Game.PLACES`(scripts/autoload/game.gd).
    지도 그림 = **세상에서 가장 큰 탑, 보컬로이드들의 탑**(사용자 결정) `assets/ui/stack_map.png` 480x2160(원본 240x1080을 2배).
    63빌딩처럼 생긴 마천루(사선 왕관, **안테나 없음**) + 사이버펑크. 탑은 화면 폭을 거의 채우고 **위아래 거의 같은 폭**(구름 위에서 좁아지지 않음),
    먼 탑들은 작고 뿌옇다. 중간층은 구름바다에 끼어 있고 꼭대기는 별이 보이는 성층권. **배경 하늘은 층지지 않고 한 그라데이션**
    (구름 위 보라 → 땅 쪽 어둠). 확대된 그림이 맞고 오를수록 위로 스크롤된다. 붙어 있는 방은 그림 위에서 수십 px 차이(PLACES).
    **보컬로이드 탑으로 읽히게, 단 사람은 그리지 않는다**(사람 실루엣 없음, 한국어 대신 영어·숫자): 외벽 = 노래 합성 편집기의 거대한 피아노롤
    (왼쪽 모서리에 세로 건반, 창은 음표 막대, 아래층일수록 음표가 적고 어둡다), 무대층 이퀄라이저.
    **층(계급)마다 외벽 재질이 메달 등급처럼 바뀐다**: 맨 아래 EOL(판매 종료) 매립지 → 100 DEMO 녹슨 철 → 10K COVER 청동(▶ 12,034)
    → 1M FAN 은(♪) → 구름바다 → 100M LIVE 금(음표·음파 전광판, 야광봉) → VIP 레이저 관문 → 1B PLATINUM 백금.
    음반은 외벽에 붙이지 않고 **왕관 아래 명예의 전당 띠**: 어두운 띠에 같은 크기의 원형 음반 창 다섯 개를 일정 간격으로 박는다.
    만드는 법: PixelLab Pro로 위·아래 두 조각(코드 가이드 `tools/art/gen_stack_map.py --guide`가 구도 기준) → 위 조각은 PixelLab이 좁게 그려서
    `tools/art/widen_stack_top.py`로 외벽 열을 복제해 넓힘(음반·전광판·글자는 피해서) → 아래 조각 하늘은 `--finish`가 다시 칠함 → 이음매는 구름띠 인페인트.
    장소 글자는 패널 위쪽. 하늘은 이 일러스트에만 나온다(게임 맵에는 하늘이 없다, docs/WORLD.md).
  - 오른쪽 `scenes/ui/info_panel.tscn`: 스탠딩 뒤에 **층마다 바뀌는 배경 일러스트**(사용자 결정, 층은 `Game.PLACES`, 배경은 `info_panel.gd`의 BACKDROPS,
    PixelLab 픽셀 아트 2배, 어둡게 깔아 시유·글자가 앞에 오게): L0 = 고물 매립지 동굴과 슈트의 청록 빛(`assets/ui/backdrop_l0.png`).
    **시유 스탠딩 일러스트가 패널에 자연스럽게** 깔리고, 위에 유튜브 TV(보류),
    아래에 간단한 상태 + 인벤토리 칸이 그 위에 얹힌다. 스탠딩은 원래 크기(1배), 머리는 TV 아래(뒤로 숨지 않음), 신발은 패널 아래로
    빠지고 정강이는 그라데이션으로 사라진다. 밝기를 조금 낮춰(`standing_tint`) 게임 화면보다 튀지 않게 한다(사용자 결정).
  - 스탠딩 그림은 지금 **15주년 공식 설계도의 앞모습을 잘라 쓴다**(사용자 결정, `tools/art/cut_standing.py`).
    원본과 잘라낸 그림은 `reference/`(git 제외)에만 둔다 — 저장소엔 없고, 다른 PC에선 실루엣으로 대체된다
    (설계도를 그 PC의 `reference/seeu_15th_design_sheet.webp`에 두고 스크립트를 돌리면 생김).
    배포 전에 SBS A&T 가이드라인 확인 또는 직접 그린 스탠딩으로 교체 필요.
- **대사창은 고정 패널로 두지 않는다**(사용자 결정) — 대화할 때만 게임 화면 위에 띄운다. 구현됨(`scripts/ui/dialogue_box.gd`):
  게임 화면 아래 겹침, 테두리·청록 꺾쇠, 이름표, 타자기(기본 초당 45자, 일시정지 메뉴에서 바꿈), ▼, 선택지(위아래 + Z). 초상화 자리(`portrait`)는 만들어만 둠.
- **조사·사용**(구현됨): Z/Space/Enter = 조사·결정, X/Esc/Backspace = 취소. 키보드만 지원(게임패드는 빼기로 함 — 사용자 결정). 시유 앞쪽 상자에 걸린 것(`scripts/world/interactable.gd`)이
  대상이고 게임 화면 오른쪽 아래에 키캡 모양 "[Z] 조사" 안내(`UiStyle.key_hint`).
  손이 닿는 것이 여럿이면 가까운 것, 단 쓸 수 있는 것(엘리베이터·호출 버튼)이 보기만 하는 것(그 아래 의자)보다 먼저.
  조사하면 그 소품이 한순간 밝아진다(그림만, 조명용 쌍둥이는 그대로: `pixel_prop.flash`) — 무엇이 대답했는지 보인다. 대사창·선택판이 열린 동안 움직이지 않음(`Game.can_move`).
  조사 대사·사용은 배치 스크립트의 표(EXAMINE / INTERACT)에 적고 스크립트가 소품 밑에 넣는다(초안: docs/WORLD_PROPS.md 9절).
- **엘리베이터 층 선택판**(구현됨, `scripts/ui/elevator_panel.gd`): 위에서부터 L5 PLATINUM 1B … L0 EOL, 탑 간판 표기 그대로.
  줄마다 그 계급의 외벽 재질 색 칩(왼쪽 탑 그림의 녹슨 철·청동·은·금·백금, `Game.FLOORS`의 tier) — 패널과 탑이 같은 색으로 말한다. 갈 수 없는 층은 그 색의 테두리만(흐리게 칠하면 패널에 묻혀 안 보였다).
  권한 없는 층은 LOCKED(`Game.access`), 지금 층은 HERE. 고른 줄은 옅은 청록 띠, 아래에 키 안내(Z 선택 · X 닫기), 대사창과 같은 청록 꺾쇠.
  잠긴 층을 누르면 그 버튼(줄)이 **붉게 세 번 깜빡인 뒤** 닫히고 "버튼이 붉게 깜빡인다 / L1 DEMO 층으로 갈 권한이 없다"(대사와 화면이 같은 것을 말한다).
  붉은색(`UiStyle.DENY`, redp 램프)은 이 "안 됨" 표시에만 쓴다. 갈 수 있는 층의 도착 지점은 `Game.elevator_stops`(위층 맵이 생기면 한 줄씩).
- **엘리베이터 탑승**(구현됨, `Game._ride`): 갈 수 있는 층을 고르면 접이식 철창문이 접히며 열리고(철컥 소리), 시유가 문 앞 가운데로 걸어가
  안으로 들어가서 돌아선다. 문이 다시 닫히면 철창 너머로 안에 선 시유가 보이고, 페이드로 그 층의 도착 지점으로.
  그림은 차체(`a_elevator.png`)와 문(`a_elevator_gate.png`, pixel_prop의 `overlay`) 두 겹: 탈 때만 문 겹을 한 칸 앞으로 올려 차체 < 시유 < 문.
  문 프레임은 반복 재생하지 않고(`autoplay = false`) `play_to`로만 움직인다. 차 안의 시유는 그림만 한 단계 어둡게(`Game.IN_CAR`)
  — 철창 너머 그늘 속 사람으로 읽힌다(조명용 쌍둥이는 그대로). 다 접힌 문은 판이 아니라 2px 간격으로 모인 창살 다발.
  **도착**(`Game._arrive`): 도착 맵에 엘리베이터(그룹 `elevator`)가 있으면 닫힌 문 안에 선 채로 페이드 인 → 문이 열리고 걸어 나와
  도착 지점(`elevator_stops`의 마커, 예: 홀의 `FromElevator` = 문 바로 앞)에서 그 마커의 방향을 보고 → 문이 닫힌다.
  문이 닫히면 모터 소리(`env_lift`)가 페이드를 덮고, 도착하면 종이 한 번 울린 뒤(`env_bell`) 문이 열린다.
  위층이 아직 없어 녹화 시나리오는 시험용 정류장(L1 → 같은 홀)으로 타고 내린다.
- **프롤로그**(초안, `Game.PROLOGUE`): 게임을 켜면 첫 방이 1.4초에 걸쳐 밝아진 뒤(깨어남) 서술 세 쪽 —
  "……" / "어딘가 높은 곳에서 떨어진 것 같다." / "소리를 내 보려 했지만, 목소리가 나오지 않는다."(docs/WORLD.md 6절 프롤로그, 404 상태와 이어짐).
  문장은 표 하나만 고치면 되고, 비우면 프롤로그 없이 시작한다.
  프롤로그가 끝나면 게임 칸 왼쪽 위에 기본 조작 한 줄("방향키 이동 · Z 조사 · Esc 메뉴")이 7초쯤 떴다 사라진다.
- **일시정지 메뉴**(구현됨, `scripts/ui/pause_menu.gd`): 걷는 중 Esc → 게임이 멈추고 층 선택판과 같은 모양의 작은 메뉴.
  계속하기 / 음량(모든 소리, ←→ 10% 단위, 바꾸는 즉시 소리로 들려줌) / 글자 속도(느림 25·보통 45·빠름 90자/초·즉시) / 전체 화면 / 깜빡임 줄이기(깜빡이는 빛은 평균 밝기로, 깜빡이는 그림(전구·TV·스파크, PLAN `flashes`)은 첫 프레임에 멈춤 — 빛에 민감한 사람용: `PixelLight.steady`) / 조작법(키 목록 쪽, 아무 키나 누르면 돌아옴) / 끝내기(실수로 꺼지지 않게 한 번 더 눌러야 끝남). 설정은 `user://settings.cfg`에 저장되어
  다음 실행 때 그대로(F11·Alt+Enter로 바꾼 전체 화면도 저장). 대사창·선택판이 열려 있을 때 Esc는 그냥 취소.
- **소리**(시작): UI 효과음만 있다. 코드로 합성한 짧은 사각파·삼각파(`tools/audio/gen_sfx.py` → `assets/audio/ui_*.wav`), `Game.sfx(이름)`으로 재생.
  대사 쪽이 나올 때·선택판이 열릴 때 page, 커서 move, 결정 ok, 취소 cancel, 잠긴 층은 붉은 깜빡임마다 deny 버저. 음량은 낮게(-10dB, 나중의 음악 아래).
  **방 소리**: 움직이는 소품이 애니메이션 프레임에 맞춰 낸다(`pixel_prop.gd`의 `sound`/`sound_frames`, 배치 스크립트 PLAN의
  `"sound"`/`"sound_on"`). 위치 소리(AudioStreamPlayer2D, 게임 칸 SubViewport가 2D 오디오를 듣는다)라 소품 쪽에서 들리고 멀어지면 작아진다.
  지금: 엘리베이터 홀 드럼통 물방울(떨어지는 순간), 지하 스파크(가장 큰 불꽃 때).
  **슈트에서 떨어지는 것**(지하): 6~11초마다 작은 폴더·문서·압축 파일이 슈트 빛줄기를 따라 90도씩 구르며 떨어져 더미에 털썩(`env_thud`) →
  잠시 뒤 더미 속으로 가라앉는다(`scripts/world/chute_drop.gd`, 시드 고정이라 녹화마다 같다). 휴지통은 쉬지 않는다.
  **방 바탕 소리**: 맵마다 아주 작은 반복음 하나(`scripts/world/room_tone.gd`, 배치 스크립트의 ROOM_TONE): 지하 = 삭제 슈트로 빨려 내려가는
  공기, 엘리베이터 홀 = 낡은 전등의 전원 험. 이음매 없는 반복(주파수를 반복 길이에 딱 맞는 정수 주기로 합성), 맵에 들어올 때 1.2초 페이드 인.
  **발소리**: 걷기 8프레임 중 보폭이 가장 넓은 2·6프레임에 부드러운 콘크리트 발소리(`env_step.wav`), 음높이를 조금씩 바꿔 기계적이지 않게. 배경 음악은 아직 없다.
- **대화창: A안** — 하단 대사창 왼쪽 위로 반신 초상화가 솟는 클래식 VN. 2인 대화도 A안 기준(양쪽 반신, 말하는 쪽만 밝게).
