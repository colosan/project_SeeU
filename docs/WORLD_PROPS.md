# 세계관 소품 목록 (인터넷 속 가상 세계)

이 세계는 인터넷 안이다([DESIGN.md](DESIGN.md) "세계 컨셉"). 지하 고물상 = **휴지통 / 쓰레기 수집(GC) 구역**,
천장 슈트 = 위층에서 지운 데이터가 떨어지는 삭제 경로, 버려진 안드로이드 = 쓰지 않게 된 아바타·단종된 음성 모델의 몸체.
그래서 평범한 고물도 "데이터"라는 단서를 단다. 글자 설명보다 **사물 말장난**을 우선한다.

- 생성: `python tools/art/gen_digital.py` (없는 파일만 씀, 덮어쓰기는 `--force 파일명`, 아무것도 지우지 않음)
- 미리보기(3배): `python tools/art/gen_digital.py --preview=폴더` → 전/후 비교, 새 소품, 방 더미, 시유 크기 비교 시트
- 결과: `assets/env/basement/digital/` (96개). 도구: `tools/art/digitize.py`(디지털 단서), `tools/art/pixfont.py`(3x5 글꼴), `tools/art/gen_digital.py`
- 규칙은 [ART_PIPELINE.md](ART_PIPELINE.md)와 같다: 원본 해상도, 램프 색만, 실루엣 외곽선 한 번, 윗면+앞면만, 왼쪽 위 빛, 잡점 금지, 씨앗 고정.
- **방에 놓는 것은 조용하게**(ART_PIPELINE.md 9~10절, 2026-10 정리): 더미·탑·버려진 단품은 꺼진 모습(화면 = 검은 유리, LED 꺼짐, 스텐실 없음)이고
  기울고·눕고·묻힌다. 빛나는 것은 이야기 광원뿐(`gen_emission.py` STORY_EMITTERS). 아래 표의 "빛나는" 묘사는 단품을 따로 쓸 때(켜진 판) 기준이다.

## 1. 디지털 단서 (어떤 코드 그림에도 붙일 수 있음, `digitize.py`)

방 전체 예산: 디레즈 3곳(빛나지 않는 블록, `HEAP_ACCENTS`), 텍스처 빠짐 1곳, 와이어프레임 0, 읽히는 글자 4개(404·EOL·127.0.0.1·GC).

| 단서 | 모습 | 쓰는 곳 |
|---|---|---|
| 디레즈(de-rez) | 실루엣 한 모서리가 2x2/1x1 블록으로 깨지고, 몇 개가 위로 떠오르며 작아지다 희미한 청록 데이터가 됨(지워진 데이터가 썩어 가는 중) | 더미마다 1~3곳(꼭대기 아래 어깨에), 의자 등받이, 사다리 끝, 트러스 끝, 스피커 모서리 |
| 텍스처 빠짐 | 탁한 자홍(corrupt) + 가장 어두운 강철 체크무늬 | 아바타 가슴판, 의자 방석, 텍스처 빠진 블록. 이미지마다 예산 0~2개라 방 전체에 아주 조금 |
| 와이어프레임 | 물체 일부가 5px 격자 + 대각선의 어두운 청록 선만 남은 미완성 메시(속이 비쳐 보임) | 아바타 머리 반쪽, 몸통 오른쪽·팔 |
| 확장자/상태 글자 | 3x5 픽셀 글꼴, 3배에서 읽힘: .ZIP .WAV .TMP .EXE .BAK 404 ERR 01 MEM 56K UDP 418 EOL | 스티커·스텐실·화면 |

디레즈 조각은 원래 물체의 경계 상자 밖으로 나가지 않는다 → 디지털판은 원본과 **크기·밑선이 같다**.

## 3. 방 더미 1:1 교체본 (`dg_` + gen_junk 이름)

`dg_z_*`(10), `dg_c_*`(6), `dg_e_0..11`(12), `dg_t_*`(4), `dg_s_*`(7), `dg_a_spark/tv/rack/fan`(4), `dg_d_0..5`(6),
`dg_f_puddle1/2`, `dg_f_plate1`, `dg_f_coil1`, `dg_pile_a/b/c`, `dg_crate/amp/rack/tv` — 총 60개.

- 파일 이름이 같아 레이아웃 PLAN에서 그대로 바꿔 쓴다. 단품·바닥 장식은 원본과 크기·밑선이 같다.
- **더미(`dg_z/c/e_*`, `dg_pile_*`)는 조용한 더미(`dheap`)**: 같은 씨앗·폭·높이, 부품은 원본의 약 1/4(크고 적게), 전부 기울고·눕고·뒤집히고 반쯤 묻힘,
  밑에 어둡게 누른 삼켜진 고물 실루엣, 몸통은 잡점 없는 어두운 덩어리. 높이는 원본과 조금 다르다(레이아웃 검사로 확인).
- **쌓은 묶음(`dg_t_*`)은 기운 탑(`dstack_lean`)**: 앰프 탑(6·15·30도로 점점 기움), 압축 상자 둘 + 기댄 스피커, 팔레트 위에 옆으로 쓰러진 서버, 비트 버킷 위에 12도 기운 켜진 TV(방의 화면 둘 중 하나).
- 애니메이션: `dg_a_spark` 8f/10fps(불꽃만, 날아가는 데이터 비트 없음), `dg_a_tv` 6f/6fps(오류 대화상자 화면이 깜빡이는 TV가 고물 덩이 위로 13도 기울어 있음, 프레임 33x22),
  `dg_a_rack` 6f/5fps(더미에 -9도로 기댄 레거시 서버, 흐린 LED 4개만, 프레임 24x34), `dg_a_fan` 4f/12fps(방에서는 뺌).
- `dg_s_worklamp`는 원본과 **완전히 같다**(빛의 원천이고, 지운 데이터가 아니라 GC 작업반의 도구).
- 바닥 장식(`dg_f_*`, `dg_d_*`, `dg_a_bugs`, `dg_a_lan`)은 gen_junk처럼 외곽선 고리가 없다.

## 8. 통합할 때 참고

- **런타임 램프**(`digitize.py`가 실행 중에 `pix.RAMPS`에 추가, pix.py는 안 고침). 받아들여지면 pix.py로 옮긴다:
  - `corrupt` `1e1320 381c35 54284c 723866 8e5080` — 탁한 자홍, 유일한 두 번째 강조색(글리치·텍스처 누락), 아주 조금만
  - `paper` `27241f 45413a 6a6559 928c7c b9b29f` — 문서·스티커·파일 아이콘·커서
  - `icon` `2a2416 4b4128 6f6040 94824f b5a265` — 폴더 아이콘(탁한 마닐라색)
  - 기존 램프와 겹치는 색 없음(검사함). gen_emission은 이 색을 모르므로 자홍은 빛나지 않는다(의도).
- **발광 마스크**: `tools/art/gen_emission.py`가 glow 2단 이상·spark를 자동으로 잡되, `basement/digital`은 **STORY_EMITTERS 목록의 파일만** 빛난다:
  `dg_s_worklamp`(전구), `dg_a_spark`, `dg_a_tv`, `dg_t_barrel_tv`, `dg_a_rack`(LED, 빨간 LED `redp 4` 포함), `dg_a_meme_fine`(불꽃 끝).
  목록 밖(홀로그램·로딩 링·모뎀·파이프 등 단품 애니메이션 포함)은 켜진 그림이어도 빛나지 않는다. 쓰려면 이유와 함께 목록에 추가.
- **지금 지하 방 PLAN**(2026-10 정리, 46 → 32개, 단품 28 → 14): 이야기 소품만 단품으로 둔다 —
  404 대화상자(그녀와 함께 떨어짐), 쓰러진 휴지통 통, EOL 상자(그녀의 것), 127.0.0.1 매트(양탄자 끝), GC 로봇(출구 옆), 불타는 방 밈 구석,
  작업등 2개, 스파크 전선, 깜빡이는 TV, LED가 남은 서버, 미끄러져 앉은·누운 아바타, 쏟아진 케이블.
  뺀 것: 커서, 시바견 인형, 트롤 얼굴, 스팸 통조림, 버그, HELLO WORLD 출력물, 스피커 단품, 마이크 스탠드, 아바타 머리·팔·다리, 환풍기, 기름 웅덩이, UI 창 조각.
  파일은 지우지 않았다(다른 방이나 위층에서 쓸 수 있음).

## 9. 조사 대사 (초안 — 바꿔도 됨)
조사(Z)하면 대사창에 나오는 글. 배치 스크립트의 표에 있다: 지하 `tools/layout_basement.py`의 EXAMINE, 엘리베이터 홀
`tools/layout_elevator_hall.py`의 INTERACT(엘리베이터·호출 버튼은 층 선택판을 연다). 고친 뒤 배치 스크립트를 다시 돌린다.
- 말투는 3인칭 서술 "~다"체(시유의 목소리가 아직 없으니 독백 대신 서술). 짧게, 한 쪽에 한 문장.
- 지하: 404 오류 창, EOL 상자, 127.0.0.1 매트, 쓰러진 휴지통, 앉은 아바타, GC 로봇, 불타는 작은 방(밈), 깜빡이는 TV, 누운 아바타, 비트 버킷 위 화면, 스파크, 작업등, 압축 파일 상자, 해체된 무대, 기댄 서버·쓰러진 서버.
- 엘리베이터 홀: 층별 안내도(층 이름은 탑 간판 표기 PLATINUM·LIVE·FAN·COVER·DEMO), 드럼통, 손수레, 운전수 의자.
